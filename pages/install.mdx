# System Requirements
Agar aplikasi Varmasi dapat berjalan dengan lancar, direkomendasikan menggunakan komputer dengan specs berikut
 - Operating System: Windows 10 / 11
 - Dual Core CPU or above
 - RAM 4 GB Minimum
 - 10 GB Free Storage
