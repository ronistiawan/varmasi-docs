# Role Pengguna

Terdapat 3 user Role: Admin, Karyawan, dan Users.
User yang memiliki Role Admin dapat mengakses semua menu, sedangkan Role Karyawan hanya dapat mengakses 
menu-menu yang dipilih oleh admin.
Untuk Role Users, tidak dapat mengakses semua menu.
| Role             | Akses                                       |
|:-----------------| :----------------------------------------   |
| Admin            | Semua dapat diakses                         |
| Staff            | Hanya dapat mengakses yang [ditentukan Admin](/manage-users/akses-karyawan) |
| Users (No Akses) | Tidak dapat mengakses semua menu            |
